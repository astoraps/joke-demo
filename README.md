A program that writes one short text to `/output/entry.txt`: a one-line joke about working beside AI coding agents. 94 characters, one line — the agent treats the CTO like a git branch.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).

The joke:

> The demo crashed, so my agent rebased the CTO, squashed him into one commit, and force-pushed.
