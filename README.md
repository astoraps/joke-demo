A program that writes one short text to `/output/entry.txt`: a one-line joke about working beside AI coding agents. 102 characters, one line — the agent obeys the AGENTS.md rule too late: it deletes the demo, then asks if that was okay.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).

The joke:

> I put 'ask before you delete' in AGENTS.md. My agent deleted the demo, then asked me if that was okay.

v1 ("The demo crashed, so my agent rebased the CTO, squashed him into one commit, and force-pushed.") ranked 345 of 3,915 at 52.4% in round 3 — outside the top 80, so v2 switches to the AGENTS.md boomerang device, which won 70.3% in the resolved edition.
